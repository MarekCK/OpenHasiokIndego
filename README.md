# OpenHasiokIndego

ESP32-S3 based robotic mower project.
PSZOK Engineering™

Hardware:
- Bosch Indego 400 chassis
- ESP32-S3
- BTS7960
- Bosch 5S Li-Ion battery
- Wheel encoders
- Boundary wire sensors
- Resistive joystick - ESP32C6
